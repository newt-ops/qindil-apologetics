# Security Policy

## Responsible Disclosure

Qindil Apologetics takes the security of our platform and team data seriously. If you believe you have discovered a security vulnerability in this project, we request that you report it to us responsibly.

### Reporting a Vulnerability

Please **do not** report security vulnerabilities via public GitHub issues.

Instead, please send a detailed security report to:
📧 **security@qindilapologetics.com** (or **contact@qindilapologetics.com**)

In your report, please include:
- A description of the vulnerability and potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the issue.
- Any relevant request/response logs or screenshots.

### Our Commitment

- We will acknowledge receipt of your security report within 48 hours.
- We will investigate the issue promptly and keep you informed of our progress.
- Once fixed, we will publish appropriate security advisories if applicable.

Thank you for helping keep Qindil Apologetics safe!
